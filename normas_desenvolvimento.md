# Normas de desenvolvimento
- Atomic design estrito  
- Modulo css para classes de estilo  
- Tailwind apenas para layout e estrutura de página  
- HTML totalmente semântico (div, article, aside, main, section, nav, header, footer...)  
- Estrutura padrão:
    componente -> index.tsx(estrutura, flex, grid, etc... com tailwind), index.module.css(estilos visuais), index.function.tsx(métodos utilizados pelo componente ou pela página)
